PINTOR PRO PORTUGAL 3.0 — PWA
Versão atualizada com cálculo por Área Total da Casa.

Novo modo:
- Introduz a área total da casa (m²).
- Define um fator de paredes editável (por defeito 2,5).
- A área estimada de paredes = área da casa × fator.
- Se "Incluir tetos" estiver ativo, soma também a área do pavimento.
- Portas e janelas são descontadas.
- O fator é uma estimativa e deve ser ajustado à geometria real da casa.

Publicar no GitHub Pages:
1. Colocar estes ficheiros na raiz do repositório.
2. Settings > Pages.
3. Deploy from a branch.
4. Branch: main / root.
5. Guardar.
